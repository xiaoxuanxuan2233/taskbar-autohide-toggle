# Taskbar Toggle · 中文使用说明

双击 TaskbarToggle.exe 打开设置，无需安装额外文件。适用于 Windows 10/11 x64 和 .NET Framework 4.x。

1. 点击“开启自动隐藏”，鼠标移到任务栏所在屏幕边缘即可显示。
2. 默认 Ctrl + Alt + Z 切换隐藏状态。点击快捷键框，按下新组合，再“保存设置”。被占用的组合会提示更换。
3. “开机自启”首次默认勾选。建议保持开启，登录后随时可用。重点：点击“保存设置”才生效，程序会复制到 %LOCALAPPDATA%\TaskbarToggle，登录时只在托盘运行。取消勾选并保存即可关闭，关闭后的选择会记住。
4. 点击“桌面快捷方式”创建入口，双击可打开设置。
5. 点击“选择图片…”，选 PNG/JPG/BMP/GIF/ICO。拖动裁剪框移动，拖右下角缩放，也可输入 X、Y 和边长。输出可选 32/64/128/256 像素，点“使用图标”后保存。图标更新到托盘和桌面快捷方式。
6. 关闭窗口收起到托盘；双击托盘图标重新打开。右键托盘图标可切换状态或退出。

建议：图标用清晰图片，输出优先选 256。小图放大可能模糊。快捷键避开复制、粘贴等常用组合。

重点：开启自启不会强制改变任务栏状态。退出后状态保留，快捷键停止响应。更新前先退出旧版本，再运行新版本并保存。

界面语言可切换中文 / English，保存后记住。使用 Windows 消息响应事件，没有轮询和联网请求。
